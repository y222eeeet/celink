# Celink

관계 기반 이벤트 초대 및 아카이빙 플랫폼 (MVP)

## iOS (Xcode)

1. `celink/celink.xcodeproj` 를 Xcode로 엽니다.
2. 시뮬레이터 또는 기기에서 **Run** (⌘R).

## Web (Next.js)

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인합니다.

Vercel 배포: 루트 디렉터리에서 Next.js 프로젝트로 Import.

## 웹 구현 기능

- **홈** — 내가 만든 이벤트, 리마인더, 다가오는 이벤트, 최근 업로드, 최근 참여, 초대받은 이벤트
- **만들기** — 5단계 이벤트 생성 (타입·기본정보·커버·식순·미리보기)
- **프로필** — 장부 금액, 장부 열기, 출금하기, 내가 만든/참여한 이벤트
- **이벤트 상세** — 주최/참여 역할별 UI, 식순, 방명록·앨범 프리뷰, 하단 CTA
- **RSVP** — 참여/미참여/늦게 참여/미정, 늦게 참여 시 시간 선택
- **방명록** — 목록·작성·비공개
- **공유 앨범** — 3열 그리드, 업로드, 좋아요·댓글, 주최자 비공개/삭제
- **축하하기** — 프리셋·직접입력 결제 시뮬레이션
- **장부** — 주최 이벤트 축하금 내역
- **참여자 관리** — RSVP·관계 필터
- **출금** — PG 연동·송금완료 시뮬레이션 후 장부 차감

상태는 클라이언트 메모리(`AppStoreProvider`)에 저장됩니다. 새로고침 시 초기화됩니다.
